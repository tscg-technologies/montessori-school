================================================================================
LITTLE SPROUTS MONTESSORI SCHOOL - DEMONSTRATION WEBSITE
================================================================================

PROJECT OVERVIEW:
This is a modern, premium, fully responsive demonstration website for a fictional
Montessori School based in India ("Little Sprouts Montessori School").
Built strictly using pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
Zero external frameworks, build tools, package managers, or server runtimes.

HOW TO RUN:
Simply double-click or open `index.html` in any modern web browser
(Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).
No installation or web server is required.

TECHNOLOGIES EMPLOYED:
- Semantic HTML5 (header, nav, main, section, article, footer, blockquote)
- Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Transitions, Keyframe Animations)
- Vanilla JavaScript ES6+ (IntersectionObserver, DOM event handling, Accordion logic,
  modal lightbox with keyboard controls, client-side enquiry validation)
